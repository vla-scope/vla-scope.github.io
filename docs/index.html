VLA-Scope: Shift-Aware Failure Prediction
for Vision-Language-Action Models

Kaiwen Zhu1, Dongfang Liu2, Liangkai Liu1
1Texas Tech University2Purdue University
Paper 𝒳arXiv Code

VLA-Scope characterizes initial input shifts and predicts failure from partial executions by combining shift context, action-prefix features, and cumulative execution-step representations.

Abstract

Vision-language-action (VLA) models map visual observations and natural-language instructions to robotic actions, but distribution shifts can compromise their reliability. Because these models may still succeed under out-of-distribution (OOD) conditions, detecting OOD inputs alone is insufficient to predict execution failure. In this paper, we introduce VLA-Scope, a two-stage framework that combines input-shift characterization with execution history to predict failure during OOD rollouts. The first stage uses pooled image and language representations to detect OOD inputs and classify their shift categories. For inputs flagged as OOD, the second stage combines the predicted category, action-prefix features, and execution progress features. A logistic regression model shared across shift categories updates failure risk as execution proceeds. We evaluate the framework with OpenVLA on ten LIBERO-Spatial tasks using leave-one-group-out cross-validation. OOD detection achieves a ROC-AUC of 0.9454, and shift classification achieves 91% accuracy. Evaluated independently of the OOD gate on all 1,400 OOD rollouts, the failure predictor achieves a ROC-AUC of 0.8497 after 60 executed actions, compared with 0.7906 without execution progress features. It also achieves higher ROC-AUC than the evaluated ActProbe and SAFE-MLP baselines. These results suggest that combining action features with temporally aggregated execution-step representations improves failure prediction under input shifts.

OOD Does Not Imply Failure

Across the seven evaluated OOD categories, observed failure rates range from 27.5% for Layout to 77.5% for Camera. Every category contains both successful and failed executions. The shift category provides useful context, but execution evidence is needed to predict an individual rollout's outcome.

VLA-Scope: From Input Shifts to Failure Risk

The framework has two stages:

  • OOD Characterizer. At initialization, pooled image and language representations are used for ID/OOD detection and OOD type classification. The predicted category remains fixed within a rollout.
  • Failure Risk Predictor. During execution, 14 action-prefix features, a seven-dimensional predicted-type encoding, and a 32-dimensional cumulative representation are combined into a shared logistic regression model. Risk is updated from action 10 onward using only the available execution history.

The cumulative representation averages execution-step representations from step 10 to the current step, followed by training-fitted standardization and PCA. Output scores are not temporally smoothed. Under gated operation, an ID decision returns no failure-risk score; it does not imply task success.

Experiments

We evaluate VLA-Scope with OpenVLA on ten LIBERO-Spatial tasks using Leave-One-Group-Out cross-validation, holding out an entire task in each fold. The evaluation includes 500 ID inputs and 1,400 OOD rollouts across seven shift categories.

Does accumulating execution evidence improve failure prediction?

Failure-risk ROC-AUC increases from 0.6852 at 10 actions to 0.7675 at 30 actions and 0.8497 at 60 actions. All 1,400 OOD rollouts remain in evaluation at these checkpoints. At later checkpoints, completed rollouts leave evaluation, so the evaluated cohort changes.

What do actions and cumulative representations contribute?

Removing the cumulative representation reduces step-60 ROC-AUC from 0.8497 to 0.7906; removing action features reduces it to 0.8344. Both reduced variants retain predicted OOD type, supporting the complementary value of action features and cumulative representations.
